Build a website-based presentation.

Recommended implementation:
- Vite
- React
- TypeScript
- CSS modules or Tailwind CSS
- No heavy backend required

Features:
- Slide-by-slide navigation
- Keyboard navigation: ArrowRight / ArrowLeft
- Clean code blocks with copy buttons
- Reference links visible on relevant slides
- Responsive layout
- Dark theme preferred
- Optional light/dark toggle
- Optional small “Live Coding” badge on demo slides

Design:
- Modern technical style
- Minimal text per slide
- Strong visual hierarchy
- Monospace code blocks
- Use comparison tables
- Emojis allowed but not excessive

Content density:
- Each slide should contain enough context to be understandable.
- Avoid paragraphs longer than 2–3 lines.
- Prefer diagrams, tables, and short bullets.
- Do not include speaker notes.

Live coding slides:
- Must contain copyable Swift code.
- Clearly mark them with “Live Coding”.
- Code should be complete enough to paste into a Playground or Swift file.
- Live coding sections are:
  1. Calendar and date arithmetic
  2. Reproducing common bugs
  3. Formatting and parsing
  4. davedelong/time docs walkthrough, but do not invent unverified APIs

References:
- Add references per slide where relevant.
- Use small footer links or a reference panel.
- At the end, include a full references slide/page.
